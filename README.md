######UPD5
**(CS16CLIENT)**
**Сегодня было обнаружено то что радио команды на кнопках z x c могут работать достаточно прописать в консоль _extended_menus 0. Помимо этого можно заставить работать меню настроек игры и ботов во время матча. Для этого нужно забиндить любые клавиши на команды exec touch/cmd/cmd и exec touch/bots/bots, например bind h touch/cmd/cmd. Эти меню умеют использовать мышку и при помощи них вы сможете легко настроить ботов, записать демку, настроить режим меню и многие другие вещи.**

**We found out today that radio commands on the buttons z x c can work if you just write _extended_menus 0 in the console. In addition, you can make the menu of game settings and bots work during the match. To do this you need to bind any keys to the commands exec touch/cmd/cmd and exec touch/bots/bots, for example bind h touch/cmd/cmd. These menus can use the mouse and with them you can easily customize bots, record a demo, customize the menu mode and many other things.**
